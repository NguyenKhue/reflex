"Network & Internet" screen of Settings: Wi-Fi, Mobile network, Data usage, Mobile plan, VPN, Airplane mode, hotspot rows.
The values under each row (network name, data used) change with device state: never match on them. The top-left arrow
("Navigate up") goes back to the main list. Read-only: do not toggle Wi-Fi, VPN or Airplane mode.
